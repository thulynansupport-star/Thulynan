# Thulynan — Production AI Agents, Workflow Automation & Web Platforms

Intelligent digital infrastructure engineered to scale modern businesses. Built with React 19, Vite, and complete SEO, AEO, and GEO optimization.

---

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start Vite React development server
npm run dev

# Build production bundle
npm run build

# Preview production build locally
npm run preview
```

---

## 🌟 Key Features

- **Pixel-Perfect Modern Design**: Clean slate/white base with refined amber accents, responsive mobile navigation, and interactive hero carousel.
- **Interactive Components**:
  - `Header`: Sticky scroll shadow and mobile menu drawer.
  - `Hero`: Automated 3-service showcase carousel with animated progress bars, pause on hover, and core pillar stats.
  - `Services`: Commercial pillars (Web Platforms, Featured AI Solutions, Business Automation).
  - `Process`: 5-Phase agile delivery methodology.
  - `Impact`: 24/7 AI support, manual work reduction, sub-second web performance.
  - `About`: Studio story and co-founders Archanaa S & Srimathi E.
  - `FAQ`: Accessible question accordion.
  - `Contact`: Direct booking, global route vector map, timezone coverage, and interactive inquiry form.
  - `AiWidget`: Floating "Thulynan AI Copilot" with instant answer chips and automated replies.
- **SEO & AEO Ready**:
  - Full Schema.org JSON-LD structured data (`Organization`, `ProfessionalService`, `FAQPage`, `BreadcrumbList`, `WebSite`).
  - Standardized `/llms.txt` for AI crawlers (Perplexity, ChatGPT, Claude).
  - OpenGraph, Twitter Cards, canonical tags, and multilingual `hreflang` alternates.
- **GEO Geotargeting**:
  - Geotagging meta headers (`geo.region`, `geo.placename`, `geo.position`, `ICBM`).
  - Dual local authority (Erode / Coimbatore, Tamil Nadu, India) and global timezone alignment (US, UK, EMEA, India, APAC).
